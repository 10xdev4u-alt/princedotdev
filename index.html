Publish static HTML drafts from your terminal

A developer utility for authenticated static HTML publishing. Upload plans, reports, and pages directly from the CLI.

$npx postplan upload./plan.html
~/project - zsh
$ npx postplan upload --title "Q4 Roadmap" ./roadmap.html
✓ Uploading ./roadmap.html...
✓ Published successfully
→ https://postplan.dev/d/8f3k2j
$ cat ~/.postplan/config.json
{ "api_url": "https://postplan.dev", "drafts": [{"id":"8f3k2j","file":"./roadmap.html"}] }
$
// How it works

Simple workflow, powerful results

01

Upload your draft

Run a single command to upload any static HTML file. No build steps, no config files needed.

npx postplan upload ./plan.html
02

Get a public URL

Instantly receive a shareable URL. Your HTML is served as-is with proper content headers.

https://postplan.dev/d/:id
03

Manage and track

Anonymous by default. Sign in to link drafts to your account and manage them over time. Local mappings stored in ~/.postplan.

npx postplan signin

// API

Simple endpoints

POST/api/upload

Upload a static HTML file. Returns a public URL with draft ID.

GET/d/:id

Retrieve a published draft by its unique ID.

GET/healthz

Service health and status check endpoint.
